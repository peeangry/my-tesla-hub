# My Tesla Hub 🚗

หน้า launcher เว็บใบเดียว รวมลิงก์แอปหลายตัว ไว้เปิดบนจอ Tesla ผ่านเบราว์เซอร์ในรถ

## เปิดใช้งาน

เปิด URL นี้ในเบราว์เซอร์ของรถ Tesla:

```
https://peeangry.github.io/my-tesla-hub/
```

> ครั้งแรกต้องเปิด GitHub Pages ก่อน: ไปที่ **Settings → Pages** ของ repo นี้
> แล้วเลือก **Source: Deploy from a branch**, Branch = `main`, folder = `/ (root)` แล้วกด Save
> รอสัก 1–2 นาที URL ด้านบนก็จะใช้งานได้

เพื่อความสะดวก แนะนำให้ **บันทึกเป็น Bookmark** ในเบราว์เซอร์ Tesla ไว้กดเปิดได้เร็วๆ

## ฟีเจอร์

- 🌙 ธีมมืด ปุ่มใหญ่ กดง่ายบนจอสัมผัส (ดีตอนกลางคืน ลดแสงรบกวน)
- ⏰ นาฬิกา + วันที่ (ปฏิทินไทย) เปิดดูได้ขณะขับ
- ➕ **เพิ่ม/ลบแอปเองได้จากในรถ** — กดปุ่ม "แก้ไข" แล้วเพิ่มชื่อ + ลิงก์
  รายการที่เพิ่มเองจะถูกเก็บไว้ในเบราว์เซอร์ (localStorage) ไม่ต้องแก้โค้ด
- 📱 รองรับแอปยอดนิยม: YouTube, Netflix, Disney+ Hotstar, TrueID, AIS PLAY,
  Twitch, Spotify, Google Maps, ChatGPT, Claude และแอปเสียงเครื่องยนต์ EV

## แก้รายการแอปเริ่มต้น (ในโค้ด)

เปิดไฟล์ `index.html` แล้วแก้ที่ตัวแปร `DEFAULT_APPS` ด้านบนของ `<script>`:

```js
const DEFAULT_APPS = [
  { name: "YouTube", url: "https://www.youtube.com", icon: "📺", color: "#FF0000" },
  // ... เพิ่ม/ลบได้ตามต้องการ
];
```

## ⚠️ ความปลอดภัย

หน้านี้ออกแบบให้เปิด "ดู" ได้ขณะขับ แต่การตั้งค่า/พิมพ์/เลือกแอป
ควรทำขณะจอด หรือให้ผู้โดยสารช่วย เพื่อความปลอดภัยในการขับขี่

## ข้อจำกัด

- ต้องมีอินเทอร์เน็ตในรถ (Tesla Premium Connectivity หรือ Wi-Fi)
- แอปวิดีโอ (เช่น Netflix/YouTube/AIS PLAY) รถ Tesla จะเล่นวิดีโอได้เฉพาะ
  ตอนจอด (เกียร์ P) เท่านั้น ขณะรถวิ่งจะถูกบล็อกตามข้อกำหนดความปลอดภัยของ Tesla
